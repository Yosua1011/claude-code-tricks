Create a simple OpenAI chatbot CLI application with the following requirements:

1. Set up a new Python project with proper structure
2. Create a virtual environment if it doesn't exist
3. Install the openai package (use latest version, don't pin to old versions)
4. Build a terminal-based chatbot that:
   - Maintains conversation history
   - Supports streaming responses
   - Has a clean, colorful interface using the rich library
   - Allows users to type 'exit', 'quit', or 'bye' to end the conversation
   - Shows a typing indicator while waiting for responses
5. Store the OpenAI API key in a .env file (don't hardcode it)
6. Include proper error handling for API errors, rate limits, and network issues
7. Add type hints to all functions
8. Follow all guidelines in CLAUDE.md
9. Create a requirements.txt file
10. Add a README.md with setup and usage instructions
